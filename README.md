# SaltSaver × MedPrior AI

Beginner-friendly React + Flask + XGBoost demo. This project uses **synthetic data and illustrative prices only**. Its model score is not clinical triage, does not assess urgency, and must not guide medical decisions. The catalogue is not a verified substitution list; ask a clinician/pharmacist before switching.

## Folder contents
- `backend/generate_datasets.py`: generates the two CSVs.
- `backend/train.py`: trains/evaluates/saves an XGBRegressor and preprocessing pipeline.
- `backend/app.py`: Flask endpoints for score demo, medicine catalogue and simple history/savings logging.
- `frontend`: React/Vite interface.

## Setup
### 1) Generate datasets
```bash
cd backend
python generate_datasets.py
```

### 2) Backend setup and train
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python train.py
python app.py
```
Flask starts on `http://127.0.0.1:5000`.

### 3) Frontend
In a separate terminal:
```bash
cd frontend
npm install
npm run dev
```
Open `http://localhost:3000`.

## Dataset
The target score is generated by an arbitrary synthetic formula for a programming/ML demo. It is not based on clinical evidence. The alternative-price dataset is illustrative, not live or verified pricing.
